# sabaa-plugins · إضافات سبعة لـ Claude

## sabaa-cowork: مدرّب Claude Cowork بالعربي

إضافة بتخلّي Claude تبعك يصير مدرّب وهو معك بشغلك الحقيقي. مبنية من كورس «Claude Cowork من الأول للآخر»:
- ١٥ مهارة، وحدة لكل ورشة.
- ٥ أوامر: `coach` و`grade` و`review` و`practice` و`next`.
- وكيل مراجعة بيطلّع الأغلاط بس.

### التركيب: الطريقة الأسهل (بتتحدّث لحالها)

١. افتح Claude، وروح على **Customize ← Plugins**.
٢. اضغط **Add ← Add marketplace**.
٣. الصق: `Hmedan92/sabaa-plugins`
٤. بتطلع **Sabaa cowork**. اضغط Install.

### التركيب من ملف

نزّل `sabaa-cowork.zip` من [Releases](https://github.com/Hmedan92/sabaa-plugins/releases/latest). بعدين **Customize ← Plugins ← Add ← Upload plugin**، وارفع الملف.

### الأمان

ما في موصّلات، ولا مفاتيح، ولا سكربتات. كل شي بيشتغل بحسابك وبصلاحياتك، وما في شي بيتبعت أو بيتمسح بدون موافقتك.

### English

Arabic (Levantine) coach plugin for Claude Cowork. Add this repo as a marketplace (`Hmedan92/sabaa-plugins`) and install `sabaa-cowork`, or upload the zip from Releases.
