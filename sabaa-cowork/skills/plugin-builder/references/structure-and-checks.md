## ١. شجرة الإضافة

```
team-starter/                 ← اسم الإضافة
├── .claude-plugin/           ← إجباري (فولدر مخفي)
│   └── plugin.json           ← الملف الوحيد هون
├── skills/
│   └── weekly-status/        ← اسم الفولدر = name
│       ├── SKILL.md
│       └── references/format.md
├── commands/
│   └── weekly-status.md      ← فوقه description
├── agents/
│   └── reviewer.md           ← فوقه name وdescription
├── hooks/hooks.json          ← اختياري
├── .mcp.json                 ← اختياري، بدون مفاتيح
├── README.md
└── LICENSE
```

ممنوع: `bin/` بالجذر. بيمنع التركيب كله.

## ٢. plugin.json

```json
{
  "name": "team-starter",
  "version": "0.1.0",
  "description": "Starter plugin for a small team…",
  "author": { "name": "[[اسمك أو اسم الفريق]]" }
}
```

`name` الحقل الإجباري الوحيد. `[[اسمك أو اسم الفريق]]` مكان فاضي لازم يتعبّى قبل المشاركة. وانتبه لـ JSON صحيح: فاصلة زايدة بعد آخر حقل بتفشّل الرفع.

## ٣. الأسئلة الثمانية

| # | السؤال |
|---|---|
| ١ | **plugin.json لحاله:** جوّا .claude-plugin/ في plugin.json بس، وهو JSON صحيح؟ |
| ٢ | **الاسم:** kebab-case، وما بيبلّش بـ claude- أو anthropic-، ونفس اسم الفولدر؟ |
| ٣ | **bin:** ما في bin/ بالجذر؟ |
| ٤ | **كل Skill:** اسم الفولدر = name، والوصف شو + متى؟ (درس S1) |
| ٥ | **الأسرار:** ما في مفتاح ولا كلمة سر ولا key= بأي ملف؟ |
| ٦ | **الموصّلات:** كل موصّل برابط، ومش محلّي، ومش معتمد على user_config بدون قيمة؟ |
| ٧ | **الأماكن الفاضية:** ما في [[...]]؟ |
| ٨ | **النسخة:** version ارتفع؟ |

## ٤. أغلاط من ملفات تمرين الكورس (وهمية)

| الغلط | ليش مشكلة | الحل |
|---|---|---|
| `bin/sync-policies.sh` بالجذر، بينسخ من /Volumes/HR | بيمنع التركيب، والمسار مش موجود بالسحابة | امسح bin/ |
| `"url": "https://…/mcp?api_key=sk_live_…"` بـ .mcp.json | المفتاح بيوصل لكل الفريق | امسح المفتاح، وغيّره (اعتبره انكشف)، والموصّل من تبويب Connectors |
| `"name": "claude-hr-kit"` | الاسم ممنوع يبلّش بـ claude-، وهو دائم | hr-ops-kit، نفس اسم الفولدر |
| `.claude-plugin/skills/apa-citations` | جوّا .claude-plugin بس plugin.json | انقله لـ skills/apa-citations بالجذر |
| فولدر `lecture_cards` والاسم `lecture-cards` | اسم الفولدر لازم = name | سمّي الفولدر lecture-cards |
| موصّل بـ `${user_config.drive_folder}` بدون قيمة | Cowork ما بيسأل، فبيتجاهله | رابط بدون user_config، أو قيمة افتراضية |
| فاصلة زايدة بعد author بـ plugin.json | JSON غلط، الرفع بيفشل | امسح الفاصلة |
| موصّل محلّي (`"command": "node"` ومسار على الجهاز) | ما بيشتغل بالسحابة | موصّل بعيد (`"type": "http"` ورابط)، أو ملف بيرفعه |
| `[[سعر الساعة]]` و`[[اسم الاستوديو]]` ما تعبّوا | بيطلعوا بأول عرض سعر | «شو الأماكن الفاضية اللي بعدها؟» وعبّيهم |

## ٥. أخطاء شائعة

- فولدرات جوّا .claude-plugin/ ← الـSkills ما بتتحمّل.
- اسم بيبلّش بـ claude-، أو تغيير الاسم بعد المشاركة ← الاسم دائم.
- مفتاح بـ .mcp.json أو برابط ← الإضافة بتنشارك مع الكل.
- فولدر bin بالجذر ← الإضافة كلها ما بتنركّب.
- موصّل محلّي لفريق بالسحابة ← ما رح يشتغل عند حدا تقريباً.
- إضافة كلها وكلاء، والفريق بالمحادثة ← الوكلاء ما بيتحمّلوا. إمّا Cowork، أو المراجعة جوّا الـSkill.
- مشاركة بدون سؤال الأماكن الفاضية.
- نسيان رفع version.
- ملفات كبيرة جوّا الإضافة ← الحد ٢٠٠ ميغا.
- تركيب إضافة من حدا ما بتعرفه بدون ما تنقرا.
