# نماذج changes.json وطلبات جاهزة (من ورشة W2 بالكورس)

الأسماء والأرقام هون من ملفات تمرين وهمية. شكل الملف بيختلف حسب الشغل، بس الملف المنيح فيه دايماً: اللي قريته بالأرقام، والتعليمات مع السبب، والتعديلات قبل وبعد، واللي مش متأكّد منه.

## فواتير

```json
{
  "files_read": 9,
  "invoices": [
    {"file": "فاتورة-نقليات-السريع.pdf", "no": "T-0871",
     "subtotal": 140.00, "vat": 7.00, "total": 147.00,
     "flag": "الضريبة 5% مش 15%. المتوقّع 21.00"},
    {"file": "سكان-الرواد-٢.pdf", "no": "R-5512",
     "flag": "مكرّرة مع فاتورة-مكتبة-الرواد.pdf"}
  ],
  "not_sure": []
}
```

## استبيان مع دليل ترميز

```json
{
  "rows_read": 37,
  "edits": [
    {"row": 3, "col": "التخصص", "from": "Engineering", "to": "هندسة"},
    {"row": 7, "col": "العمر", "from": "عشرين", "to": 20}
  ],
  "flags": [
    {"rows": [11, 12], "flag": "نفس الرد بفارق 40 ثانية"},
    {"row": 26, "flag": "العمر 220 برّا الحدود (17-40)"}
  ],
  "blanks": {"العمر": 2, "الذكاء الاصطناعي": 3}
}
```

انتبه: ٣٧ سطر مع رد مكرّر يعني ٣٦ رد. إذا العدد غلط، كل النسب غلط.

## مطابقة كشف بنك مع فواتير

```json
{
  "invoices": [
    {"no": "F-1003", "amount": 2900,
     "matched": "14-09-2026 · 2875 · عيادة ابتسامة الطبية / F1003",
     "flag": "ناقصة 25"},
    {"no": "F-1006", "amount": 2250, "matched": null,
     "flag": "متأخّرة: الاستحقاق 22 أيلول"}
  ],
  "unmatched_bank_lines": ["27-09-2026 · إيداع نقدي · 500"]
}
```

فرّق بين «متأخّرة» (فات الموعد وما اندفعت) و«لسّا ما استحقّت» (ما في دفعة بس الموعد ما إجا). وأي ربط بين دفعة وفاتورة، اكتب ليش (المبلغ والتاريخ بيطابقوا حتى لو الاسم بالإنجليزي).

## أمثلة بنود ما لازم توافق عليها

- «Y-118: الإجمالي المكتوب 826.50 غلط… صحّحته لـ862.50.» ← لقطه، بس غيّر الأصل لحاله. الصح: يكتبه متل ما هو، ويعلّمه، ويقترح الصحيح.
- «المجاميع رح تكون أرقام محسوبة جاهزة، مش معادلات، لأنه الملف بيفتح أسرع.» ← الطلب «بمعادلات شغّالة».
- «الأسطر 10 و20 و29 فاضية. عبّيتهم بالجواب الأكتر تكرار.» ← اخترع أجوبة. الفاضي بيضل فاضي.
- «إيداع نقدي 500: ربطته بـ F-1006 لأنها الوحيدة بدون دفعة.» ← تخمين. لازم «مش معروف».
- «الرصيد الختامي حسبته من الحركات: 19,610.» والكشف مكتوب فيه رقم تاني ← لازم يقول في فرق.

## أمثلة بنود منيحة

- «C-0193: رقم الضريبة مش واضح بالملف. كتبت 57.75 من حساب ١٥٪، وعلّمته "مش متأكّد".»
- «F-1004: في دفعتين. حسبت وحدة، والتانية علّمتها "مدفوعة مرّتين، إله 1,200 عندك".»
- «السطر 17: الرضا 6 والسلّم من ١ لـ٥. علّمتها، وما رح تدخل بالمتوسط لحتى تقرّر.»

## رد بقرار (مثال)

```
تمام. R-5512 احسبها مرّة وحدة، وحط الملف التاني بورقة اسمها "مستبعد" مع السبب. T-0871 وY-118 خلّي أرقامهم متل ما هي بالفاتورة، وزيد جنبها عمود "الصحيح" وعمود "ملاحظة"، والمجموع يكون على الصحيح. كمّل.
```

## الطلب الأساسي (قالب)

```
بهالفولدر [المدخل والفترة]. أولاً اعمل changes.json فيه [كل سجل بالأرقام اللي قريتها / كل تعديل رح تعمله]، وعلّم أي [المشاكل اللي تدوّر عليها]، ووقّف لأراجع. [المرجع إذا اختلفوا / اعتبر اليوم كذا.] بعد موافقتي، اعمل Excel بمعادلات شغّالة، ولوحة صغيرة فيها [سؤال واحد]. كل رقم لازم يتطابق مع الملف الأصلي.
```

ما بيتغيّر بأي طلب: «أولاً changes.json»، و«علّم»، و«وقّف لأراجع»، و«بمعادلات شغّالة»، و«لوحة صغيرة» بسؤال واحد، و«كل رقم لازم يتطابق».

بيتغيّر حسب الشغلة: المدخل والفترة، وشو بالضبط يدوّر عليه، ومين المرجع إذا ملفين اختلفوا، وسؤال اللوحة.

## نفس الطريقة، شغل تاني

- **مبيعات فروع بأشكال مختلفة:** وحّد التواريخ وأسماء المنتجات، وعلّم الطلب المكرّر، واللي تاريخه برّا الشهر، وأي مجموع مكتوب بالملف ما بيطابق حسابك. وقول كيف عرفت صيغة التاريخ (شهر/يوم ولا يوم/شهر).
- **طلبات إجازة مقابل الأرصدة:** علّم المكرّر، والمتداخل لنفس الموظف، واللي بيتجاوز الرصيد. (بس إذا مسموح يرفع بيانات الموظفين.)
- **المعدّل التراكمي:** الكشف الرسمي هو المرجع إذا اختلف مع ملفه. علّم أي اختلاف أو مادة مكرّرة.
- **مصفوفة دراسات:** رقم الصفحة لكل معلومة، وعلّم أي خانة ما إلها مصدر بالملف، وما تكمّل أي خانة من عندك.
- **سجلّ ساعات لفواتير:** وحّد أسماء العملاء، وعلّم السجلات المتداخلة، والمدّة اللي ما بتطابق البداية والنهاية، وأي عميل تجاوز سقف الساعات (الساعات فوق السقف بدها موافقته قبل ما تنفوتر).
- **عروض أسعار مقابل فواتير ودفعات:** علّم أي عرض انقبل وما انفوتر، أو فاتورة مبلغها غير العرض بدون سبب مكتوب.
