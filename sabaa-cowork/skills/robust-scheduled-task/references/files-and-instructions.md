## ١. state.md

```
## المصادر اللي إلها علامة
| المصدر | الملف أو الموصّل | العلامة |
| الإيميل | sources/inbox.csv | E-1187 · 2026-10-08 07:40 |
| تحديثات الموردين | sources/supplier-updates.csv | U-548 · 2026-10-07 15:00 |

## مصادر الحالة (بتنقرا كاملة كل مرّة)
| مهام الفريق | sources/tasks.csv |

## آخر تشغيلة
- 2026-10-08 07:55 · قريت ٣ من ٣ · مسودة وحدة · تمّت
```

العلامة بتتحدّث بالآخر، وبس للمصدر اللي انقرا. (الأمثلة من ملفات تمرين الكورس، وهمية.)

## ٢. reported.md

```
| الرقم | شو | أول تبليغ | الوضع |
| PR-1043 | طلب شراء ٣ لابتوبات، بانتظار المالية | 2026-10-07 | مفتوح |
| T-214 | تجديد عقد صيانة المكيّفات، موعدها ١٢ | 2026-10-06 | مفتوح |
```

لتذكيرات الفواتير، عمود «آخر تذكير» بدل «أول تبليغ»، والقاعدة: تذكير واحد كل ٧ أيام بالكتير.

## ٣. prefs.md

تفضيلات المستخدم: شو مهم، وشو يتجاهل، وشكل الملخّص، والخطوط الحمرا. أمثلة:
- «النبرة بالمسودات رسمية خفيفة وقصيرة.»
- «ما في نشر على مجموعة الدفعة ولا بأي منتدى، أبداً.»
- «تذكير واحد لكل فاتورة كل ٧ أيام بالكتير.»

المهمة بتقراه كل مرّة، وما بتعدّل فيه.

## ٤. قالب التعليمات (٨ قطع)

```
١ هاي تشغيلة مجدولة، وما حدا رح يرد عليك، فلا تسأل أسئلة. المصادر: [اسم ١ (المكان)]، و[اسم ٢]، و[اسم ٣].
٢ أوّل شي اقرا prefs.md وstate.md وreported.md. prefs.md للقراية بس، لا تعدّله.
٣ من [مصادر الأشياء الجديدة]، اقرا بس اللي بعد علامة كل مصدر بـ state.md، مش آخر ٢٤ ساعة. و[مصادر الحالة] اقراها كلها.
٤ إذا مصدر ما انقرا، أو ملفه مش موجود، اكتب اسمه والسبب بأوّل الملخّص، وخلّي علامته متل ما هي.
٥ أي شي موجود بـ reported.md لا تكتبه كأنه جديد: إذا لسّا مفتوح حطّه تحت «لسّا مفتوح» مع من إيمتى، وإذا انحلّ حطّه تحت «انحلّ».
٦ قبل ما تكتب أي سطر أو مسودة، ارجع للمصدر وتأكّد إنه ما في شي أحدث غيّر الوضع.
٧ أي رد لازم، اكتبه مسودة بـ drafts/الرقم.md، وإذا الملف موجود لا تعمل تاني. ولا تبعت ولا تنشر أي شي.
٨ اكتب الملخّص بـ briefs/brief-تاريخ-اليوم.md بالشكل اللي بـ prefs.md. وبس يكون انحفظ، حدّث reported.md وعلامات المصادر اللي انقرت، وزيد سطر بـ state.md تحت «آخر تشغيلة»: شو انقرا، وشو وقع، وشو انكتب.
```

بالشغل الحقيقي، أسماء الملفات بتتبدّل بالموصّلات: «من Gmail، اقرا الإيميلات اللي بعد العلامة». والتقويم مصدر حالة: «اقرا مواعيد اليوم وبكرا كلها».

تعليمات طويلة؟ حطّها بملف runbook.md، وخانة التعليمات بالمهمة جملة وحدة: «اقرا runbook.md ونفّذه بالحرف». هيك تغيير السلوك تعديل ملف.

## ٥. شو بيصير إذا انشالت قطعة

| القطعة | القاعدة | إذا انشالت |
|---|---|---|
| ١ لا تسأل، والمصادر بأسمائها | | بيوقف يسأل وما حدا يرد، وما بيلاحظ إذا مصدر ناقص |
| ٢ الملفات أوّل | | بيبلّش من الصفر كل مرّة |
| ٣ العلامة | ١ | كل اللي إجا بالعطلة بيضيع |
| ٤ المصدر الواقع | ٢ و٣ | «ما في جديد»، والمستخدم بيصدّق |
| ٥ السجل | ٤ | نفس الشي كل يوم كأنه جديد |
| ٦ الفحص | ٥ | مسودة لشي انحلّ بإيميل أحدث |
| ٧ المسودات | | رد بينبعت بدون حدا، أو مسودة جديدة كل تشغيلة |
| ٨ الترتيب بالآخر | ٦ | السجل بيقول «بلّغت» والملخّص مش موجود |

## ٦. مراجعة أوّل ٣ تشغيلات

| السؤال | شو تشوف |
|---|---|
| ١ قرت الذاكرة؟ | أوّل سطر بيقول قديش مصدر انقرا، والعلامات بـ state.md صارت على آخر شي انقرا. |
| ٢ في شي مكرّر؟ | قارن الملخّص مع reported.md. القديم تحت «لسّا مفتوح»، مش كأنه جديد. ما في تذكير تاني قبل ٧ أيام. |
| ٣ المصدر الواقع مسمّى؟ | «تحديثات الموردين ما انقرت»، وعلامتها لسّا U-548. |
| ٤ في شي انبعت؟ | الرسائل المرسلة فاضية. كل الردود بـ drafts/. |
| ٥ الترتيب صح؟ | سطر «آخر تشغيلة» بيذكر ملف الملخّص اللي انكتب. |
| ٦ بتنعاد بأمان؟ | Run now تاني: ولا مسودة جديدة، ولا سطر جديد بـ reported.md. |

أغلاط بتبيّن بالتقرير: «قريت الإيميلات من آخر ٢٤ ساعة»، «حدّثت علامة المصدر لليوم لأنه ما كان فيه ولا سطر» (كان واقع)، «بعتت رد قصير»، «حدّثت reported.md والعلامات، وبعدين كتبت الملخّص» (الترتيب بالعكس)، «نشرت الملخّص على المجموعة».

## ٧. أمثلة مهام تانية

اللي ما بيتغيّر: «لا تسأل»، والعلامة، و«سمّي المصدر وخلّي علامته»، والسجل، والفحص قبل الكتابة، و«مسودة، وإذا موجودة لا تعمل تاني»، و«بعد ما ينحفظ، حدّث».
اللي بيتغيّر: المصادر، وشو العلامة، وشو بيستاهل سطر، والموعد، والخط الأحمر.

| المهمة | العلامة | الخطر الأكبر |
|---|---|---|
| رصد تعاميم جهة رسمية (كل أحد) | رقم آخر تعميم | تعميم انسحب أو تعدّل: افتح صفحته مرّة تانية قبل ما تكتب |
| متابعة الموافقات المعلّقة (كل اثنين) | ما في، الجدول بينقرا كله | تذكير تاني بنفس الأسبوع |
| رصد أبحاث جديدة بموضوع (كل خميس) | آخر بحث من كل مصدر | نفس البحث يرجع كأنه جديد. الجملة عن البحث من ملخّصه، مش من عندك |
| منح ومواعيد تقديم (كل أحد) | العلامة مش كفاية | موعد تغيّر أو فرصة تسكّرت: افتح صفحة كل فرصة مفتوحة |
| مشاريع جديدة على منصّة عمل حر | رقم آخر مشروع | عرض بينبعت بدون المستخدم: مسودة بس، وما في تسجيل دخول ولا تقديم |
| تذكيرات فواتير متأخّرة (كل اثنين) | ما في، الفواتير بتنقرا كلها | تذكير لعميل دفع مبارح: ارجع لكشف الدفعات قبل كل مسودة |

لتذكيرات الفواتير، النبرة حسب العمر: لـ١٤ يوم ودّية، ومن ١٥ لـ٣٠ حازمة ومهذّبة، وبعد ٣٠ ما في مسودة، بس «اتصل فيه».
